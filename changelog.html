🚀 Initial Release - Version 1.0

June 4 2026 - Simple Viewer is now available!

  • Core image viewing with smooth zoom and pan.
  • Powerful crop tool with aspect ratio presets made very simple.
  • Image transforms: rotate, mirror, flip, resize
  • Support for animated GIFs and many formats (PNG, JPEG, WebP, HEIC, etc.)
  • Right-click context menu for all actions (no traditional menu bar)
  • Full screen mode (F11)
